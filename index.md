# rclone personal client

This site describes a personal Google OAuth client used with [rclone](https://rclone.org), an open-source command-line tool for syncing files with cloud storage.

The client is used only by its owner, Johnny Wannamaker, to sync files between their own computer and their own Google Drive. It is not a public service and does not accept other users.
