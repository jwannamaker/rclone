# Privacy Policy

Effective date: October 11, 2026

## What this app is

This OAuth client is used with rclone, an open-source program that runs on the owner's own computer. It is for the personal use of its owner only.

## Google user data accessed

With the user's permission, the app accesses Google Drive files and file metadata (names, folders, sizes, modification times) using the Google Drive API.

## How the data is used

Data is used only to copy and sync files between the owner's computer and their Google Drive. It is not used for advertising, analytics, or any other purpose.

## Storage

Files are transferred directly between Google's servers and the owner's computer. No data is sent to or stored on any server run by the app's developer. The OAuth access token is stored only in the rclone configuration file on the owner's computer.

## Sharing

Google user data is not sold, shared with, or transferred to any third party.

## Revoking access and deleting data

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the rclone configuration file removes the stored token.

## Limited Use

This app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
